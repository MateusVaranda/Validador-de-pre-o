## 📌 Sobre o Projeto

O **Validador de Financiamento** é uma aplicação web interativa que permite informar o valor total de uma compra e o valor de entrada, realizando cálculos automáticos e apresentando o resultado de acordo com regras de negócio predefinidas.

O projeto foi desenvolvido com o objetivo de praticar lógica de programação, manipulação do DOM, validação de dados e estruturas condicionais utilizando JavaScript.

## ⚙️ Funcionalidades

- Entrada do valor total da compra.
- Entrada do valor disponível para pagamento.
- Cálculo automático do saldo restante.
- Validação dos valores informados.
- Análise do percentual de entrada.
- Classificação do resultado como aprovado ou reprovado.
- Feedback visual dinâmico para cada resultado.

## 🧠 Conhecimentos Aplicados

### JavaScript
- Declaração de variáveis com `const`.
- Conversão de valores com `Number()`.
- Manipulação do DOM com `getElementById()`.
- Gerenciamento de eventos com `addEventListener()`.
- Prevenção do comportamento padrão com `preventDefault()`.
- Estruturas condicionais `if/else`.
- Operadores aritméticos e de comparação.
- Manipulação de conteúdo com `textContent`.
- Manipulação de classes com `classList`.
- Controle de visibilidade com `hidden`.

### HTML5
- Estruturação semântica com `main` e `section`.
- Criação de formulários com `form`.
- Utilização de `label`, `input` e `button`.
- Integração dos elementos HTML com JavaScript.

### CSS3
- Organização de layouts com Flexbox.
- Estilização de campos e botões.
- Pseudo-classes `:focus` e `:hover`.
- Responsividade com Media Queries.
- Personalização visual dos resultados com classes CSS.

## 🎯 Objetivo

Consolidar conhecimentos fundamentais de desenvolvimento Front-End, aplicando conceitos de HTML, CSS e JavaScript na construção de uma aplicação funcional e interativa.
